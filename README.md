# Arduino-Code-Incubator

A collection of Arduino sketches and code examples.

## Sketches

| Sketch | Description |
|--------|-------------|
| [Blink](./Blink/Blink.ino) | Blink the built-in LED on and off every second |

## How to Use

1. Open the Arduino IDE.
2. Navigate to the sketch you want to use.
3. Open the `.ino` file.
4. Connect your Arduino board and upload the sketch.
